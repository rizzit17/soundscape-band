# SoundScape simulation-only evaluation

This is synthetic numerical data, not wearable recordings, a trained recognition
dataset, physical vibration measurements, or participant data. The submission
does not include a hardware or operational recognition prototype.

## Dataset inventory

- Main: 100 streams, seeds 3001–3100, each 1,200 seconds; **3,594 events**.
  Thirteen policies/ablations produce **46,722 event-policy outcome rows**.
  Those rows are repeated evaluations of the same events, not independent events.
- Stress: seven conditions, seeds 4001–4030 per condition, 30 streams each.
  Seed IDs are reused across conditions; do not pool them as independent sessions.
- Deadline: seeds 5001–5030, 30 streams, each tested at 150, 300 and 500 ms.
- Total: 340 condition-seed stream realizations, 113.33 generated hours.
- Acoustic: **4,200 scenes** = seven conditions × three triangle sides × two
  SNRs × two source types × 50 seeds. All/strongest-bin estimates are paired
  within each scene, giving **8,400 estimate rows**. Both source types are tested
  at every seed direction. The independent resampling unit is the seed cluster,
  retaining its layout, source-type and SNR repetitions.

Source types are broadband Gaussian noise and a 420 Hz harmonic surrogate,
not natural recordings. Triangle sides are 25, 35 and 50 mm; SNR reference is
unit-RMS unattenuated source amplitude; sample rate is 16 kHz and window is
64 ms. Conditions include free field, a second source, a delayed-copy reflection
surrogate, fixed timing offset, correlated noise, gain mismatch and cross-faded
motion. The moving comparison uses the centre angle and does not model Doppler.
Fractional delays are circular FFT shifts. Gain mismatch is not body shadowing,
and a single delayed copy is not a validated reverberant-room simulation.

## Reproduction

Use Python 3.12 (study: 3.12.14) and NumPy 2.3.5. From the archive project root:

```text
python -m pip install -r requirements-study.txt
python python/final_simulation_study.py --workers 4
python python/supplement_simulation_study.py
python python/test_final_study.py
```

The first script runs fixed numerical protocols. The second adds a single-motor
control without retuning and computes acoustic seed-cluster intervals. This is
an additional diagnostic, not a claimed preregistered experiment. It is safe to
repeat: it replaces that control's outcome rows rather than duplicating them.

To regenerate a complete main score/direction trace and its event annotations:

```text
python python/final_simulation_study.py --export-stream 3001
```

A sample trace for this seed accompanies the archive. There are no audio WAV
files because the main policy dataset consists of generated class scores and
direction observations. Acoustic samples can be regenerated by the seeded code.

## Numerical files

- `study_results.json`: settings, seeds, source hashes, runtime versions,
  per-stream metrics, uncertainty intervals, paired tests and acoustic summaries.
- `event_outcomes.csv.gz`: main event/alert matches for all 13 policies; includes
  true class/angle, alert class/angle, motor mask, latency and evidence index.
- `acoustic_trials.csv`: 8,400 estimates with paired seed, source, layout, SNR,
  condition, true/estimated direction, gate outcome and each reliability value.
- `SHA256SUMS.txt`: hashes of supplied numerical files. Reproduction changes
  host elapsed-time metadata and gzip timestamps; compare numerical fields,
  not byte hashes of an independently regenerated archive.

Class indices: horn 0, siren 1, shout 2, reversing beep 3, ambient 4.
Angles increase clockwise from front. Virtual motor bits: front 1, right 2,
back 4, left 8; 15 is a general four-motor command, not physical vibration.

## Metrics and inference

The first non-update alert from onset through offset+500 ms defines detection.
Wrong-class alerts still count for class-agnostic timing; correct-class and timely
correct-class rates are separate. Extra within-event alerts are not ambient false
alarms; total notification burden additionally counts all non-update outputs.
Wrong-direction and miss/late rates use all events, general-warning fraction
uses detections, and angular error uses directional first detections. Timing is
on the model clock and does not measure actuator or processor latency.

Primary estimates are unweighted mean stream metrics. Confidence intervals use
20,000 whole-stream bootstrap samples. Acoustic comparisons use 50 seed clusters.
Sign-flip tests use 100,000 assignments with a plus-one correction; Holm adjustment
covers 16 specified primary contrasts. These are exploratory simulation inferences
under assumed distributions, not guarantees about real environments or users.

The original policy/generator/localizer implementations are unchanged from the
project reference implementation. File hashes in the JSON identify exact sources.
Existing methods and inherited algorithms are not claimed as novel components.
