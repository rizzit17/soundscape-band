WHAT IS IMPLEMENTED

Signal → direction → decision

Three virtual microphones on a 35 mm triangle, 16 kHz input, fractional-lag GCC-PHAT, geometric checks and the existing DEDA policy. A 64 ms hop makes each decision inspectable.

A valid direction can produce one or two virtual motor commands. An accepted class with uncertain direction can produce a general four-motor warning.

HOW TO INTERPRET IT

A software demonstration

Passing a scene check demonstrates the stated simulated behavior. It does not measure recognition accuracy or prove a safety benefit.

Class scores are scripted. There is no measured body shadowing, calibrated room model, physical motor response, MCU timing or participant validation. The 60 ms processing allowance and 300 ms target are assumptions.

Model assumptions and metric definitions

Scene model. Procedural audio is delayed across an ideal 35 mm microphone triangle. “Reflection” adds one delayed source copy; it is not a measured room. “Timing fault” offsets one channel by three samples. These checks can accept a wrong but physically plausible angle.

Timing. First-warning delay is the first associated alert time minus source onset. “On time” means no later than 300 ms on the simulated clock. This excludes measured acquisition, processor and motor delays.

Experiment rates. Wrong direction and missed-or-late percentages use all critical events as denominator. General-warning percentage uses detected events. Only one short ambient control is included per seed, with no false-class confusers; zero false alerts cannot establish a low real-world false-alert rate.
